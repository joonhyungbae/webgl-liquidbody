# 터치디자이너로 만드는 법

브라우저 쪽(`web/`)은 그림이 어떻게 보여야 하는지를 먼저 확인하려고 둔 것입니다. 전시에서
터치디자이너로 돌릴 계획이면 이 문서를 따라 네트워크를 짜면 됩니다. 같은 그림이 나옵니다.

이 문서는 터치디자이너 없이 적었습니다. 셰이더는 GLSL TOP 문법에 맞춰 썼지만 실행해 보지는
못했습니다. 오류가 나면 아래 「오류가 나면」을 보세요.

## 1. 몸을 떼어내기 (맥에서)

맥북에서 쓸 수 있는 길이 셋입니다. 하나만 고르면 됩니다.

| 길 | 받는 곳 | 메모 |
|---|---|---|
| MediaPipe TouchDesigner | <https://github.com/torinmb/mediapipe-touchdesigner> | 맥과 윈도우에서 돈다. 설치가 필요 없고 분리 마스크를 TOP 으로 준다 |
| AppleVisionMask | <https://github.com/aaronmylespereira/AppleVisionMask-TouchDesigner> | 애플 실리콘 전용. 애플의 Vision 으로 사람만 떼어낸다 |
| appletd | <https://github.com/ojrgb/appletd> | 애플의 신경망 묶음. 분리 말고 손·자세·깊이도 같이 쓴다 |

셋 다 받는 것은 같습니다. **사람이 흰색, 배경이 검은색인 TOP 한 장**입니다. 뒤는 그것만
있으면 됩니다. 어느 것을 쓰든 다음 단계는 같습니다.

플러그인이 안 되거나 설치가 막히면, 브라우저 쪽을 띄워 두고 화면을 Syphon 으로 받는 길도
있습니다. 다만 전시에서 프로그램이 둘이 되므로 되도록 플러그인 쪽을 권합니다.

## 2. 마스크를 다듬기

```text
[분리 마스크 TOP]
   → Monochrome TOP        한 채널로 만든다
   → Blur TOP (size 2)     아주 작게. 한 프레임씩 튀는 것을 눌러 준다
   → Cache TOP 또는 Feedback TOP + Composite(0.45)
                           직전 프레임과 섞는다. 덩어리가 떨리지 않게 한다
   → Null TOP (이름: mask) 여기까지가 셰이더의 첫 번째 입력
```

섞는 비율이 브라우저 쪽 `MASK_SMOOTH` 와 같은 값입니다. 0.45 로 시작해서 떨리면 낮춥니다.

## 3. 글자 한 장 (선택)

```text
[Text TOP]  문장 하나. 배경은 투명(Alpha 0), 글자는 흰색
   → Null TOP (이름: words) 셰이더의 두 번째 입력
```

글을 안 쓸 거면 이 입력을 비워 두면 됩니다. 셰이더가 알아서 건너뜁니다.

## 4. GLSL TOP

새 GLSL TOP 을 만들고, 그 안의 Pixel Shader 에 같은 폴더의 `liquidbody.glsl` 을 통째로
붙여 넣습니다. 입력은 **1번에 mask, 2번에 words** 를 꽂습니다.

GLSL TOP 의 파라미터 페이지(Vectors · Values)에 아래 이름을 그대로 만듭니다. 이름이 한 글자라도
다르면 셰이더가 그 값을 못 받습니다.

| 이름 | 종류 | 처음 값 | 무엇 |
|---|---|---|---|
| `uTime` | float | `absTime.seconds` (식) | 흐르는 시간 |
| `uRes` | vec2 | 이 TOP 의 가로, 세로 | 화면 크기 |
| `uBleed` | float | 0.55 | 번짐 |
| `uGrain` | float | 1.0 | 결의 크기 |
| `uSoak` | float | 0.45 | 배어든 정도 |
| `uSurface` | float | 0.4 | 수면의 일렁임 |
| `uStars` | float | 0.5 | 별 |
| `uWarm` | float | 0.3 | 색 (0 새벽 ~ 1 미색) |
| `uPaper` | float | 0.35 | 종이결 |
| `uWaterTop` | float | 0.1 | 액체의 위 수면 |
| `uWaterBottom` | float | 0.1 | 액체의 아래 수면 |
| `uFront` | float | 0.1 | 지금 움직이는 수면 |
| `uRing` | float | 0 | 결계 |
| `uFade` | float | 1 | 전체 밝기 |

여기까지 꽂으면 수채화 덩어리가 나옵니다. 액체는 아직 움직이지 않습니다.

## 5. 액체가 차고 빠지게 하기

수면 두 개를 시간에 따라 움직이면 됩니다. CHOP 쪽에서 만듭니다.

```text
[Timer CHOP]   길이 = 차오르는 시간(예: 24초)
   → Math CHOP   0~1 로 맞춘다
   → Lag CHOP    처음과 끝이 느리게 (Lag 0.5 쯤)
   → Null CHOP (이름: level)
```

그다음 GLSL TOP 의 파라미터에 식을 적습니다. 몸의 위아래 끝을 `0.08` 과 `0.95` 라고 하면,

- **차오름**: `uWaterTop` 은 `0.08` 고정, `uWaterBottom` 은 `0.08 + 0.87 * op('level')[0]`
- **빠짐**: `uWaterTop` 은 `0.08 + 0.87 * op('level')[0]`, `uWaterBottom` 은 `0.95` 고정
- `uFront` 는 지금 움직이는 쪽과 같은 식을 적습니다

차오름과 빠짐을 한 Timer 로 이으려면 Timer CHOP 에 구간(segment)을 둘로 두고, 두 번째 구간에서
위아래 식을 바꾸면 됩니다. 브라우저 쪽 `web/water.js` 가 이 순서를 그대로 글로 적어 둔 것이니
옮길 때 같이 보시면 됩니다.

몸의 위아래 끝을 고정값이 아니라 사람에 맞추고 싶으면, 마스크를 Analyze TOP 으로 줄여
세로 방향의 처음과 끝을 재서 쓰면 됩니다. 처음에는 고정값으로 두고 나중에 바꾸는 편이 낫습니다.

## 6. 내보내기

```text
[GLSL TOP] → Level TOP(밝기 맞추기) → Null TOP → Window COMP 또는 Out TOP
```

TV 로 갈지 프로젝션으로 갈지는 이 뒤에서 갈립니다. 프로젝션이면 Window COMP 를 그 화면으로
보내고, 필요하면 Kantan Mapper 로 모서리를 맞춥니다.

## 오류가 나면

| 이런 일이 생기면 | 이렇게 합니다 |
|---|---|
| GLSL TOP 이 빨갛게 되고 오류가 뜬다 | 오류 줄 번호를 보고 그 줄만 고칩니다. `vUV`, `sTD2DInputs`, `TDOutputSwizzle` 은 터치디자이너가 알아서 만들어 주는 것이라 따로 적지 않습니다 |
| 화면이 까맣다 | 첫 번째 입력에 마스크가 꽂혔는지, 그 마스크가 흰색과 검은색인지 봅니다 |
| 사람이 보이지 않는다 | 마스크가 뒤집혔을 수 있습니다. Invert TOP 을 한 번 넣습니다 |
| 글자가 위아래로 뒤집혀 보인다 | Flip TOP 을 글자 쪽에 넣습니다. 브라우저 쪽에서도 같은 자리에서 한 번 걸렸습니다 |
| 느리다 | GLSL TOP 의 해상도를 1280×720 으로 낮춥니다. 번짐이 클수록 무겁습니다 |
| 액체가 몸 밖으로 샌다 | 번짐이 너무 큽니다. `uBleed` 를 내리거나 `uGrain` 을 올립니다 |

## 브라우저 쪽은 어디에 쓰나

- 값을 빨리 찾는 데 씁니다. 조절판을 움직여 마음에 드는 번짐과 색을 찾고, 그 숫자를 위 표에
  그대로 적습니다.
- 터치디자이너가 아직 손에 안 익은 동안 작품의 흐름을 보여 주는 데 씁니다.
- 전시 당일 플러그인이 말을 안 들을 때의 대비책으로 둡니다. 노트북 한 대와 크롬만 있으면 돕니다.
