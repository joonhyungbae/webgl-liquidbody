작가가 만든 액체 영상을 여기에 둡니다. 저장소에는 올라가지 않습니다.

애프터이펙트나 파이널컷에서 만든 영상을 그대로 넣으면 됩니다. 화면의 「액체 영상 열기」로
고르거나, 주소에 `?clip=clips/물.mp4` 처럼 적습니다.

만들 때의 요령입니다.

- 화면 가득 채우는 영상으로 만듭니다. 몸 모양으로 오리는 일은 프로그램이 합니다.
- 배경 없이 액체만 있는 편이 좋습니다. 어두운 바탕에 밝은 흐름 정도면 충분합니다.
- 길이는 8초에서 20초 사이로, 처음과 끝이 이어지게(루프) 만듭니다.
- 1280 폭이면 넉넉합니다. 더 크면 노트북이 무거워집니다.
- 소리는 넣지 않습니다. 음악은 따로 틉니다.
